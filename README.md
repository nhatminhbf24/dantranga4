# AutoPack Print - Công cụ Dàn Trang In Ảnh A4 Tự Động

Ứng dụng dàn trang in ảnh A4 tự động thông minh, tối ưu diện tích giấy, tùy chỉnh kích thước hàng loạt, hỗ trợ in trực tiếp và xuất file ảnh độ phân giải cao 300 DPI.

## ✨ Tính năng nổi bật

- **Tải ảnh linh hoạt**: Chọn tệp từ máy, kéo thả hoặc dán trực tiếp từ clipboard (`Ctrl + V`).
- **Dàn trang tự động A4**: Tối ưu bố cục xếp ảnh theo thuật toán Shelf Packing trên khổ A4 (Dọc/Ngang).
- **Đa dạng kích thước & hình dạng**:
  - Cơ bản: 5x7cm, 6x8cm, 6x9cm (phổ biến), 9x12cm, 10x15cm (4R), 13x18cm (5R), 15x21cm (A5).
  - Ảnh thẻ: 3x4cm, 4x6cm, 4x5.5cm.
  - Hình dạng đặc biệt: Tròn (Sticker/Huy hiệu), Trái tim, Vuông Polaroid.
- **Thao tác hàng loạt**:
  - Đồng bộ kích thước cho tất cả ảnh.
  - Thay đổi số lượng bản in hàng loạt hoặc chọn nhanh 1, 2, 3, 4, 5 bản.
  - Xoay 90° toàn bộ ảnh.
- **Tương tác trực quan trên trang in**:
  - Kéo rê trực tiếp góc nhìn của từng ảnh mượt mà (1:1 pixel).
  - Cuộn chuột phóng to/thu nhỏ khung hình.
  - Modal chỉnh sửa cắt góc & xoay ảnh chuyên sâu.
  - Viền nét đứt cắt giấy (Cut lines) và Smart Portrait Crop.
- **Xuất bản & In ấn**:
  - In trực tiếp qua trình duyệt với định dạng in chuẩn A4 không viền thừa.
  - Xuất ảnh PNG / JPG chất lượng cao 300 DPI siêu nét.

## 🛠️ Công nghệ sử dụng

- **React 19** + **TypeScript** + **Vite**
- **Tailwind CSS**
- **Lucide Icons**
- **HTML5 Canvas** (render & export 300 DPI)

## 🚀 Cài đặt & Chạy ứng dụng

```bash
# 1. Cài đặt các gói phụ thuộc
npm install

# 2. Chạy môi trường phát triển (Dev)
npm run dev

# 3. Build sản phẩm (Production)
npm run build
```
